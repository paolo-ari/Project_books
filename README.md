Библиотека книг

Простое консольное приложение для управления личной коллекцией книг. Позволяет добавлять, просматривать, удалять книги, а также получать статистику по коллекции.

Как запустить

1. Убедитесь, что у вас установлен Python (версия 3.6 или выше).
2. Скачайте репозиторий или клонируйте его:
   
   git clone <URL-репозитория>
   cd <название-папки-репозитория>
3. Запустите приложение:
   
    python main.py

Пример работы

После запуска вы увидите главное меню:

--- ГЛАВНОЕ МЕНЮ ---
1. Добавить книгу
2. Показать все книги
3. Средняя оценка
4. Статистика по авторам
5. Удалить книгу
0. Выход
Выберите действие: 

Пошаговый пример использования:

Шаг 1. Добавление книги (пункт 1)

Выберите действие: 1
Введите название книги: Мастер и Маргарита
Введите автора: Михаил Булгаков
Введите оценку (1–5): 5
Введите дату прочтения (опционально): 2024-05-15
Книга 'Мастер и Маргарита' успешно добавлена!

Шаг 2. Просмотр всех книг (пункт 2)

Выберите действие: 2

--- ВСЕ КНИГИ ---
1. Мастер и Маргарита — Михаил Булгаков
   Оценка: 5
   Дата прочтения: 2024-05-15

Шаг 3. Расчёт средней оценки (пункт 3)

Выберите действие: 3

--- СРЕДНЯЯ ОЦЕНКА ---
Средняя оценка: 5.00 из 5

Шаг 4. Статистика по авторам (пункт 4)

Выберите действие: 4

--- СТАТИСТИКА ПО АВТОРАМ ---
Михаил Булгаков: 1 книга(и)

Шаг 5. Удаление книги (пункт 5)

Выберите действие: 5

--- УДАЛЕНИЕ КНИГИ ---
Выберите способ удаления:
1. По индексу в списке
2. По автору и названию
Ваш выбор (1 или 2): 1
Введите номер книги для удаления (1–1): 1
Книга 'Мастер и Маргарита' успешно удалена!

Шаг 6. Выход из программы (пункт 0)

Выберите действие: 0
До свидания!

Примечания:

При добавлении книги приложение проверяет дубликаты (не позволит добавить одну и ту же книгу дважды).

Данные сохраняются в файле books.json в той же папке, что и main.py.
